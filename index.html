          Privacy
          

            
    
              
  • Your API key is typed here and kept only in this page's memory. Reloading clears it.
    • 
              
  • The browser talks directly to api.openai.com. There is no backend, account, or analytics.
    • 
              
  • The key is always masked in request previews.
    • 
              
  • Images are sent inline with the request. Documents are uploaded to your OpenAI account and referenced by file ID; Delete uploads removes them.
    • 
              
  • OpenAI stores Responses by default. This app does not change that setting.
    • 
            

          

        


        

          API examples
          

            
Educational only. The Request tab always shows what this app actually sends.

            
Basic request


{
  "model": "gpt-5.6-luna",
  "input": "Explain quantum computing simply."
}

            
With instructions


{
  "model": "gpt-5.6-luna",
  "instructions": "Answer concisely.",
  "input": "Explain quantum computing."
}

            
With reasoning


{
  "model": "gpt-5.6-luna",
  "reasoning": {
    "effort": "medium"
  },
  "input": "Solve this problem."
}

            
With a hosted tool


{
  "model": "gpt-5.6-luna",
  "input": "What changed in the latest release?",
  "tools": [{ "type": "web_search" }]
}
